Syntax
- [ ] - [x]
a todo — anything else is just prose
- [>]
working on it right now — a third checkbox state, highlighted everywhere and filtered by Now. Set it with Ctrl+. or the ▸ beside any task
- [1] - [2]
the same, in an order — Now lists numbered work first. Click the – beside a marked task to number it
Alt+↑ Alt+↓
move the line, or the selected lines, up and down
Ctrl+X
with nothing selected, cuts the whole line
Tab on a todo
indents it into a subtask of the one above; Shift+Tab promotes it back. Ticking a task ticks its subtasks; finishing the last subtask finishes the task
@2026-08-21
due date. Also @today, @tomorrow, @fri, @aug-21, @9/1
!high #med
priority — a built-in select
#ns:value
namespaced select → its own column. Quote to use spaces: #person:"Max Weber". Repeat it on one todo for several values: #person:Max #person:Anna
~billable
boolean — present is yes, absent is an explicit no
Ctrl+F
find & replace, with match case, whole word and regex
#work
plain label — until #ns:work appears somewhere, then it resolves there
